About Alzikrayat

Alzikrayat ("The Memories") is a photo sharing web application built for the Advanced Web Technologies course at Sudan University of Science and Technology.

It is written from scratch on a custom Model-View-Controller framework over a strict three-tier architecture: a Bootstrap presentation tier, a Python application tier with a hand-written regular-expression router, and a relational data tier accessed through raw, parameterized SQL — with no web framework routing and no ORM.
